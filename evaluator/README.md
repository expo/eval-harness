# expo-evals (vendored subset)

Minimal vendored slice of `github.com/georgian-io/expo-evals` for running the
agentic evaluator inside an EAS macOS workflow job. Contains the `agentic_evaluator`
package, the `notes` reference app, the `test_insert` primitive plan, and the notes PRD.
Canonical source is the upstream repo; this is a self-contained copy for the harness.
